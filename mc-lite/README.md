# 方块猎场 mc-lite

一个 2D 侧视的打怪游戏：沿着 **480 格长**的地表走，怪物按**离出生点的距离分成 14 个难度区**一级级变硬，
挥砍它们掉材料打造更强的剑，再到悬赏板按击杀数交货换晶核；地图最东端是 **Boss 巢穴**，打死里面的墟岩魔王就通关。
风景画风沿用代码绘制的 16×16 像素贴图（不依赖任何外部美术素材），但**世界不可挖掘**——方块只是舞台和战场，不是资源。

五个特色玩法：

- **分区难度**：15 种怪按 `zone` 从出生点向外排，走到第几区就只刷第几区及以内已解锁的怪，越远越硬。
- **近战挥砍**：一刀只砍中面向方向最近的一只怪，有武器决定的射程与冷却，命中有刀光、击退和受击闪红。
- **掉材料 → 合成更强的剑**：黏液/兽皮/骨棒/翼膜/晶核全部来自怪物掉落，4 个配方逐级做出木剑到钻石剑。
- **游荡怪 + 悬赏板**：怪物在玩家两侧生成、巡逻、发现你就追击并造成接触伤害；悬赏板 3 张限时单，按击杀数交货。
- **Boss 巢穴与通关**：最东 36 列不刷普通怪，走进去才会站起来一只 Boss（独立血条 + 警告），打死即通关并弹出通关界面。

技术栈：

- 后端：Spring Boot 3.3 + Java 21 + Spring Data JPA + H2（文件库）
- 前端：Vue 3 + TypeScript + Vite 5 + Pinia + Canvas 2D
- 怪物/武器/配方/掉落/悬赏全部写在 `server/src/main/resources/content.json`，调数值不用改 Java 或 TS 代码

## 目录

```
mc-lite/
├─ server/          Spring Boot 后端（世界生成、掉落/合成/悬赏/通关结算、存档）
│  └─ src/main/resources/content.json   方块/物品/武器/配方/怪物(zone,boss)/分区规则/悬赏档位表
├─ web/             Vue 3 前端（渲染、玩家与怪物模拟、分区刷怪、Boss 巢穴、挥砍、面板）
└─ docs/架构说明.md  分层理由、协议、实测记录与已知限制
```

## 运行

需要本机已安装：**JDK 21**、**Maven 3.9+**、**Node 18+**。

```bash
# 1) 后端（默认 8080，存档写到 server/data/mclite.mv.db）
cd server
mvn spring-boot:run

# 2) 前端（默认 5173，/api 已代理到 8080）
cd web
npm install
npm run dev
```

打开 http://localhost:5173 ，输入猎场名字（种子可留空）→ 生成新世界 → 开打。
存档持久化在 H2 里，关掉浏览器再回来还在。

跑测试：

```bash
cd server && mvn test     # 32 个用例：世界生成 10 + 世界/掉落/合成/存档 9 + 悬赏 9 + 分区与 Boss 4
cd web && npm run build   # vue-tsc 类型检查 + 生产构建
```

## 玩法

**15 种怪按分区递增**（`zone = min(13, floor(|x - 出生点| / 15))`，出生点在地图正中，所以往东往西都是越远越硬）：

| 区 | 怪 | HP / 伤害 | 特点 |
| --- | --- | --- | --- |
| 0 | 史莱姆 | 12 / 3 | 出生点附近的入门怪 |
| 1 | 蝙蝠 | 14 / 4 | 飞行，会俯冲到你脸的高度 |
| 2 | 僵尸 | 20 / 5 | 慢，掉兽皮 |
| 3 | 骷髅 | 24 / 6 | 掉骨棒 |
| 4 | 洞穴蛛 | 30 / 7 | 快 |
| 5 | 荒原狼 | 36 / 8 | 最快的地面怪之一 |
| 6 | 熔岩小鬼 | 42 / 9 | 掉晶核 |
| 7 | 夜魇 | 50 / 10 | 飞行 |
| 8 | 岩魔 | 58 / 11 | 慢而厚 |
| 9 | 锈甲武士 | 68 / 12 | — |
| 10 | 岩脊蛇 | 80 / 13 | — |
| 11 | 风鸣鹰 | 92 / 15 | 飞行且快 |
| 12 | 霜岭巨人 | 108 / 16 | — |
| 13 | 深渊龙裔 | 126 / 18 | 飞行，普通怪里最硬 |
| 14 | **墟岩魔王** | **300 / 20** | **Boss，只在最东端巢穴里出现，打死即通关** |

- 刷怪只从「已解锁池」（`zone <= 当前区` 的非 Boss 怪）里挑：60% 概率出本区招牌怪，否则按权重抽，所以走远路上还会碰到弱怪，但不会碰到超区的怪。
- Boss 巢穴是地图**最东端 36 列**：走进去才生成 Boss（一次一只，配独立血条和一句警告），走出来就收回（不算击杀），通关之后巢穴是空的。
- 怪物在玩家两侧 22–46 格生成，同屏上限 14 只，走远超过 110 格自动消失；进入 aggro 半径就转向追击，被地形挡住或玩家在高处会跳。
- 接触伤害有 1 秒冷却，玩家血量归零就在出生点重生，存档进度（材料/武器/击杀数/通关标记）不丢。
- 4 级武器：徒手 T0（2 伤 / 1.6 射程）→ 木剑 T1（5/2.2）→ 石剑 T2（9/2.3）→ 铁剑 T3（14/2.4）→ 钻石剑 T4（22/2.6）。
- 4 个配方：木剑＝骨棒2+黏液2、石剑＝骨棒4+兽皮3、铁剑＝晶核2+兽皮4、钻石剑＝晶核5+翼膜4。随身可做，**不需要工作台**。
- 悬赏板：3 张限时单，**只派你已经杀过的怪**（种类不够一板时拿出生点附近 0–2 区的入门怪垫底），Boss 永远不上板。
  档位随目标怪的分区变：低区要多猎几只、给黏液兽皮；高区只猎 1–2 只、给晶核翼膜，正好接上高级剑的配方。
  倒计时归零自动换新单；交付按单子里的数量扣击杀数、发酬劳、补一张新单，多出来的猎物留着交下一单。
- 世界 480×96，同一种子生成完全一样的地形：地表起伏、地下矿脉、树、地表荧光晶。
  地下永远看不到（不能挖），所以荧光晶长在地表当风景灯，也给长地图分段做记号，夜里照亮周围一圈。
- 地表**相邻列高差最多 1 格**，跳跃高度约 1.9 格，所以 480 格能从一头走到另一头（也才走得到 Boss 巢穴）；
  树干、树叶、荧光晶标为可穿过（`passable`），不会把路堵死。
- 顶栏显示当前**区域 N / 14**，通关后留下「已通关」徽章；通关界面列出世界名、总击杀、遇到过的怪种类数与当前武器。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/content` | 方块/物品/武器/配方/怪物（含 zone/boss）/分区规则/悬赏档位表 + 简化说明 |
| GET | `/api/worlds` | 存档列表 |
| POST | `/api/worlds` | 创建（name, seed） |
| GET | `/api/worlds/{id}` | 读档：方块、背包、击杀数、血量、武器、悬赏板、通关标记 |
| DELETE | `/api/worlds/{id}` | 删档 |
| POST | `/api/worlds/{id}/loot` | 上报击杀（mob）：按掉落表发材料、累计击杀数，250ms 内重复上报拒绝；mob 是 Boss 就顺手写下通关标记 |
| POST | `/api/worlds/{id}/craft` | 合成（recipe）：扣材料、升武器等级 |
| GET | `/api/worlds/{id}/bounties` | 悬赏板（惰性清理过期单并补满 3 张）+ 服务端当前时间 |
| POST | `/api/worlds/{id}/deliver` | 交付悬赏（bountyId）：扣击杀数发酬劳并换单 |
| POST | `/api/worlds/{id}/move` | 上报玩家坐标与血量 |

掉落、合成、悬赏结算都在服务端；失败统一返回 `{code, message}`（400/404），例如 `UNKNOWN_MOB`、`LOOT_TOO_FAST`、`NO_MATERIAL`、`BOUNTY_EXPIRED`、`NOT_ENOUGH_KILLS`。

## 简化与已知限制（如实说明）

- **怪物模拟和命中判定在客户端**（走位、追击、接触伤害、挥砍命中），服务端只结算「这只怪死了」：掉落、击杀数、悬赏交货、Boss 通关标记。
  改客户端内存可以刷材料——单机本地存档没有对抗需求，但这确实是信任边界，代码注释里也标了。
- **分区、巢穴与 Boss 出现时机也全在客户端判定**：服务端不知道你在第几区、有没有走进巢穴，只认 `loot` 里那个 mob key。
  换句话说，直接对后端发一句 `loot {mob:"overlord"}` 就能把存档标成通关——这是同一条信任边界的延伸，不做服务端校验。
- **世界不可挖掘**：没有挖掘/放置/掉落方块/工具耐久，方块数组只读；地下层生成出来就永远看不到。
- 树干、树叶、荧光晶是 `passable`（可穿过）的风景：不能挖的世界里，挡路的树会把长地图永久截断。
- 怪物没有生物群系和昼夜规则，只按「离出生点的距离」分区刷；死亡不掉落物品实体，材料直接进背包。
- 武器等级自动取背包里最高级的剑，没有装备栏和耐久。
- **悬赏是惰性结算**：不开后台线程/定时器，每次读档或请求悬赏板时清理过期单、去重目标并补满 3 张；倒计时用服务端时间 offset 校准。
  悬赏单是从怪物表现场生成的（标题固定为「猎杀 N 只 XX」），不再读旧版的模板文案。
- 单人本地存档，**没有联机、没有账号**；H2 文件库单进程使用，同时只能跑一个后端实例。
- 玩家物理（重力、碰撞、跳跃）在客户端算，服务端只记录坐标血量并做范围裁剪。
- 移动端触屏布局按 CSS 媒体查询（`hover: none` / `pointer: coarse`、宽度 ≤640px）实现，**没有在真机上实测**。
- 本版之前（挖掘版）的 160×96 旧存档仍能读，地形按旧规则生成，实测相邻列高差也都是 1 格，可以正常走；想要 480 格长地图请新建猎场。
  旧档没有 `cleared` 列（读出来是 null），按「未通关」兜底，顶栏不会平白多出徽章。
- 验证方式：后端 32 个 JUnit 用例、REST 全链路联调（分区刷怪 → 击杀 → 掉落 → 合成 → 交付悬赏 → 打死 Boss 通关）、
  浏览器里实测顶栏区域徽章、Boss 血条、通关界面与悬赏板（控制台无报错）。
  **画面像素没有目视确认过**：内嵌浏览器没有可视视口（`visibilityState=hidden`），`requestAnimationFrame` 不推进，游戏循环跑不起来；
  改用临时 Node 脚本直接调用客户端的 `physics` / `mobs` / `render` 模块连真实后端跑了 49 项校验（全部通过）
  （内容表递增关系与 Boss 唯一、14 个分区各自的刷怪合法性与招牌怪比例、巢穴不刷普通怪、Boss 只在巢穴里生成且不卡进方块、
  钻石剑砍得死 Boss 且它会反击、`loot overlord` 的通关结算与幂等、悬赏板格式/数量/档位/永不派 Boss、渲染全路径含 Boss 翻转贴图），
  脚本用完已删除，不属于交付代码。
